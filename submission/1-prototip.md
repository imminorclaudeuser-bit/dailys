# Прототип — ссылка и запуск

## Рабочая веб-версия
**https://web-production-4ab12e85.up.railway.app**

Быстрый путь для проверки: «Попробовать как гость» — аккаунт без почты, сразу с шестью примерами дней (удаляется через 7 дней). Переключатель EN/RU — в нижней панели.

Что посмотреть:
1. **Записать день** → текст, фото, песня (поиск по названию) → «Отправить» → готовое воспоминание (карточка 4:5, объяснение «почему так», озвучка) и **папка дня**.
2. **Архив** → все папки, фильтр по настроениям; **Календарь** → дни в цвете настроения и итоги месяца.
3. **Отметка за 10 секунд** вверху «Записать день»: лицо-настроение + одна строка.
4. Камера (лицо + атмосфера видео) и голосовое (Whisper) работают прямо в браузере, нужен HTTPS — на ссылке выше он есть.

## Запуск у себя (≈1 минута)
Нужен **Node.js 22.13+** (без npm-зависимостей, база — встроенный `node:sqlite`).
```bash
cd ottenki-dnya
npm start            # откройте http://127.0.0.1:3000
npm test             # 56 тестов API + 13 тестов движка
```
Необязательные настройки — в `.env` (образец `.env.example`): `ADMIN_EMAIL` (админка), `GOOGLE_CLIENT_ID/SECRET` + `PUBLIC_URL` (вход через Google), `COOKIE_SECURE=1` и `TRUST_PROXY=1` за HTTPS-прокси, `DATA_DIR` (папка базы и файлов). Без них всё работает, кроме входа через Google.

Развёртывание: Railway (сервис `web`, том `/data`), обновление — `railway up --service web` (подробно в `README.md`, раздел «Deploying»).
