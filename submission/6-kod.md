# Код и технические материалы

- **`dailys-code.zip`** (0,5 МБ) — весь исходный код без больших бинарных файлов (модели ИИ, фото примеров).
- **`dailys-full.zip`** (71 МБ) — полный проект, готовый к запуску (`npm start`), с моделями Whisper/MediaPipe и фото примеров.
- В архивах нет секретов и данных пользователей: `.env`, папка `data/` исключены (есть только образец `.env.example`).
- Рабочая версия: https://web-production-4ab12e85.up.railway.app

## Архитектура (≈4 900 строк, без npm-зависимостей)
| Файл | Что делает |
|---|---|
| `server.js` | HTTP-сервер на Node 22: API дней, медиа (фото, аудио, голос, видео), сессии (HttpOnly cookie, CSRF, scrypt), вход через Google (PKCE), лимиты запросов, CSP, стена приветствия, профиль, админка |
| `moderation.js` | фильтр недобрых слов, пометки для админа |
| `public/engine.js` | **ядро системы:** анализ текста (словари настроений, отрицания, сезон, время, места), анализ фото (цвета, яркость), темп/BPM песни, `decide()` → настроение, приём, палитра, ритм, фактура, голос, **название папки** и объяснения; генеративный SVG-фон `artSvg()` и карточка 4:5 `cardHtml()` |
| `public/app.js` | экраны: приветствие, запись дня, отметка за 10 с, результат, папка дня, архив, календарь и итоги месяца, «в этот день», профиль, напоминания, админка |
| `public/face.js`, `public/media.js`, `public/whisper-worker.js` | ИИ на устройстве: выражение лица (MediaPipe → FACS), атмосфера видео, распознавание речи (Whisper) |
| `public/daisy.js`, `public/play.js`, `public/motion.js` | маскот-тюлень Дейзи, интерактивные фигуры, анимации (GSAP), фетр и полутон |
| `public/i18n.js` | все тексты интерфейса на русском и английском |
| `test/` | **69 автотестов**: 56 тестов API и безопасности (CSRF, сессии, загрузки, профиль, стена, напоминания) + 13 тестов движка (выбор приёма, палитры, названия) |

## Проверка
```bash
npm test   # Итого: 56 прошло, 0 упало / Итого: 13 проверок прошло
```

Публичного репозитория пока нет: код передаётся архивом. Чтобы выложить на GitHub: создать пустой репозиторий на github.com, распаковать `dailys-full.zip` и загрузить через GitHub Desktop или `git push` (через веб-форму файлы больше 25 МБ не загрузятся).
